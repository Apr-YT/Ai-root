# AI-Root 使用示例

## 基本使用

### 1. 安装服务（管理员权限）

```bash
# 以管理员身份运行
AI-Root install

# 验证安装状态
AI-Root status
```

### 2. 执行命令（普通用户权限）

```bash
# 以 SYSTEM 权限执行单行命令
AI-Root run "whoami /priv"

# 执行带特殊字符的命令
AI-Root run "echo Hello World"

# 执行多行脚本
AI-Root run "echo Line1 & echo Line2 & echo Line3"
```

### 3. 查看日志

```bash
# 实时查看执行日志
AI-Root tail

# 查看最近 50 条日志
AI-Root tail --count 50

# 按调用者过滤
AI-Root tail --caller "AI-Root"
```

## 高级用法

## 编程接口

### 1. Rust 集成

```rust
use std::process::Command;

fn main() {
    // 通过命名管道调用 AI-Root
    let output = Command::new("AI-Root")
        .args(["run", "whoami"])
        .output()
        .expect("Failed to execute command");
    
    let stdout = String::from_utf8_lossy(&output.stdout);
    println!("Output: {}", stdout);
}
```

### 2. Python 集成

```python
import subprocess
import json

def run_as_system(command):
    """通过 AI-Root 以 SYSTEM 权限执行命令"""
    result = subprocess.run(
        ["AI-Root", "run", "--json", command],
        capture_output=True,
        text=True
    )
    
    if result.returncode == 0:
        response = json.loads(result.stdout)
        if response["ok"]:
            return {
                "exit_code": response["exit_code"],
                "stdout": response["stdout"],
                "stderr": response["stderr"]
            }
        else:
            raise Exception(response.get("error", "执行失败"))
    else:
        raise Exception(f"AI-Root 调用失败: {result.stderr}")

# 使用示例
try:
    result = run_as_system("whoami /priv")
    print(f"退出码: {result['exit_code']}")
    print(f"输出: {result['stdout']}")
except Exception as e:
    print(f"错误: {e}")
```

### 3. PowerShell 集成

```powershell
function Invoke-AsSystem {
    param(
        [Parameter(Mandatory=$true)]
        [string]$Command
    )
    
    $result = AI-Root run --json $Command | ConvertFrom-Json
    
    if ($result.ok) {
        return @{
            ExitCode = $result.exit_code
            Stdout = $result.stdout
            Stderr = $result.stderr
        }
    } else {
        throw $result.error
    }
}

# 使用示例
try {
    $result = Invoke-AsSystem -Command "Get-Service | Select-Object -First 5"
    Write-Host "退出码: $($result.ExitCode)"
    Write-Host "输出: $($result.Stdout)"
} catch {
    Write-Host "错误: $_"
}
```


## 安全注意事项

1. **令牌安全**：令牌文件仅 SYSTEM + 用户可访问
2. **命令审计**：所有命令执行都有详细日志
3. **危险命令**：format/diskpart 等命令会被阻止
4. **超时控制**：默认 60 秒超时，最长 10 分钟

## 性能优化

1. **管道缓冲区**：64KB 缓冲区提高吞吐量
2. **连接限制**：最大 8 个并发连接
3. **超时保护**：防止长时间占用资源
4. **内存管理**：优化内存使用和释放
