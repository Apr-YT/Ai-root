# AI-Root 项目结构说明

## 目录结构

```
AI-Root/
├── src/                    # Rust 源码
│   ├── common.rs          # 公共常量、路径、令牌管理与 ACL 设置
│   ├── exec.rs            # 命令执行引擎
│   ├── main.rs            # 入口与子命令分发
│   ├── protocol.rs        # 命名管道通信协议
│   ├── server.rs          # 命名管道服务端
│   ├── service.rs         # Windows 服务管理
│   └── winapi_raw.rs      # Win32 API 原始绑定
├── docs/                   # 文档
│   ├── 优化总结.md        # 优化工作总结
│   ├── 项目结构说明.md    # 本文件
│   └── examples/          # 使用示例
├── .github/               # GitHub 配置
├── Cargo.toml             # Rust 项目配置
├── Cargo.lock             # 依赖锁定文件
├── build.rs               # 构建脚本
├── build.ps1              # PowerShell 构建脚本
├── README.md              # 项目说明文档
└── .gitignore             # Git 忽略文件
```

## 核心文件说明

### 源码文件 (`src/`)

1. **common.rs** - 公共模块
   - 令牌管理：生成、存储、轮转、缓存
   - 路径配置：数据目录、管道名称、日志路径
   - ACL 设置：目录权限、管道安全描述符
   - 日志系统：实时事件流、审计日志

2. **exec.rs** - 命令执行引擎
   - 单行命令执行：`cmd /C <command>`
   - 多行脚本执行：写入临时 `.cmd` 文件
   - 超时控制：进程监控和超时终止
   - 输出处理：stdout/stderr 截断和解码

3. **main.rs** - 入口与子命令分发
   - CLI 参数解析
   - 子命令路由：install/uninstall/start/stop/status/server/run
   - 终端着色和格式化输出

4. **protocol.rs** - 通信协议
   - 长度前缀帧格式
   - 请求/响应数据结构
   - 帧读写超时控制
   - 请求验证

5. **server.rs** - 服务端
   - 命名管道监听
   - 连接鉴权：令牌验证、节流控制
   - 并发管理：连接数限制、资源清理
   - 审计日志：执行记录、事件流

6. **service.rs** - 服务管理
   - Windows 服务注册/卸载
   - 服务启动/停止/状态查询
   - ACL 配置：智能体权限授予
   - 失败恢复策略

7. **winapi_raw.rs** - Win32 API 绑定
   - 原始 Windows API 声明
   - 安全相关的 API 函数

### 配置文件

1. **Cargo.toml** - Rust 项目配置
   - 依赖管理
   - 构建配置
   - 发布配置

2. **build.rs** - 构建脚本
   - Windows 资源嵌入（图标）
   - 构建时配置

3. **build.ps1** - PowerShell 构建脚本
   - 交叉编译：`x86_64-pc-windows-gnu` 目标
   - 产物部署

### 文档文件 (`docs/`)

1. **优化总结.md** - 优化工作记录
   - 安全增强详情
   - 性能优化说明
   - 改进对比

2. **项目结构说明.md** - 本文件
   - 目录结构说明
   - 文件功能描述

3. **examples/** - 使用示例
   - 接口调用示例
   - 集成示例

## 构建和部署

### 构建命令

```bash
# 本地构建（调试）
cargo build

# 交叉编译（Release，Windows 可执行文件）
cargo +stable-x86_64-pc-windows-gnu build --release

# 使用 PowerShell 脚本构建
powershell -File build.ps1
```

### 部署步骤

1. **构建项目**
   ```bash
   cargo +stable-x86_64-pc-windows-gnu build --release
   ```

2. **复制到部署目录**
   ```bash
   # 默认部署目录：%ProgramData%\AI-Root
   # 可用环境变量 AIROOT_DEPLOY_DIR 覆盖
   cp target/release/AI-Root.exe "$PROGRAMDATA/AI-Root/"
   ```

3. **安装服务**（管理员权限）
   ```bash
   AI-Root install
   ```

4. **验证安装**
   ```bash
   AI-Root status
   ```

## 配置和使用

### 环境变量

- `AIROOT_PIPE_NAME` - 自定义管道名称（测试隔离）
- `AIROOT_DATA_DIR` - 自定义数据目录

### 主要命令

- `AI-Root run <command>` - 以 SYSTEM 权限执行命令
- `AI-Root status` - 查询服务状态
- `AI-Root tail` - 实时查看执行日志
- `AI-Root rotate-token` - 轮转令牌

## 安全特性

1. **令牌鉴权**：32字节随机令牌，恒定时间比较
2. **管道安全**：SDDL 限制连接方权限
3. **目录 ACL**：数据目录仅 SYSTEM + 用户可访问
4. **命令安全**：危险命令模式检测和阻止
5. **详细审计**：完整的命令执行日志

## 性能优化

1. **管道缓冲区**：64KB 缓冲区提高吞吐量
2. **内存管理**：减少不必要的克隆和分配
3. **连接管理**：超时控制和资源清理
4. **并发限制**：防止资源耗尽
