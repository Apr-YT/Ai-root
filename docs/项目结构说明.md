# AI-Root 项目结构说明

本文描述仓库的目录组织与各文件职责。

> 快速上手见 [README](../README.md)；构建细节见 [构建说明.md](构建说明.md)。

---

## 目录结构

```text
AI-Root/
├── src/                        # Rust 源码
│   ├── main.rs                 # CLI 入口与子命令分发
│   ├── server.rs               # 命名管道服务端
│   ├── protocol.rs             # 帧协议与请求校验
│   ├── exec.rs                 # 命令执行引擎
│   ├── common.rs               # 令牌/路径/ACL/日志
│   ├── service.rs              # Windows 服务管理
│   └── winapi_raw.rs           # Win32 API 原始绑定
├── docs/                       # 设计与参考文档
│   ├── 安全模型.md             # ACL 隔离缺陷复盘
│   ├── 构建说明.md             # 工具链与构建坑
│   ├── 测试说明.md             # 测试矩阵与变异验证
│   ├── 项目结构说明.md         # 本文件
│   └── examples/使用示例.md    # 多语言集成示例
├── assets/                     # 图标与资源脚本
│   ├── AI-Root.ico
│   └── AI-Root.rc
├── .cargo/config.toml          # 构建配置（单一事实来源）
├── .github/workflows/ci.yml    # CI 双 job 定义
├── build.rs                    # 构建脚本（资源嵌入）
├── build.sh / build.ps1        # 构建入口（gnu / 自动选 target）
├── install-service.ps1         # 管理员安装脚本
├── Cargo.toml / Cargo.lock     # 依赖与发布配置
├── README.md / CHANGELOG.md    # 说明与变更记录
└── .gitignore / .gitattributes
```

| 文件 | 行数 | 职责 |
|---|---|---|
| `server.rs` | 1247 | 管道监听、连接鉴权（令牌校验 + 双层节流）、并发信号量、审计日志与事件流 |

| `main.rs` | 729 | CLI 参数解析与子命令路由；终端着色 |
| `service.rs` | 563 | Windows 服务注册/卸载/启停/状态；服务 DACL 授权；失败恢复策略 |
| `exec.rs` | 523 | 单行命令转义、脚本模式、超时终止、输出截断与双解码 |
| `winapi_raw.rs` | 257 | Win32 API 原始声明（安全相关） |
| `build.rs` | 94 | 资源嵌入：msvc 调 `rc.exe` / gnu 调 `windres -O coff` |

## 关键设计约定

1. **纯终端版** —— 无 GUI feature，产物只有 `AI-Root.exe`。
2. **仓库须置于纯 ASCII 路径** —— MinGW `ld` 无法正确处理含中文的产物路径。
3. **不硬编码本机路径** —— 机器相关配置由环境变量传入
   （`AIROOT_DEPLOY_DIR` / `AIROOT_RUST_ROOT` / `MINGW_BINUTILS_BIN`）。
4. **构建脚本向系统自省** —— `rustup which cargo` 而非猜测目录结构。
5. **配置与脚本职责分离** —— 稳定的进 `.cargo/config.toml`，机器相关的留在脚本。
6. **测试必须调用真实被测代码** —— 不 mock IO，不重抄逻辑。
